# 实验四验收说明 · A

本轮在同一台 Windows 宿主和同一对隔离来宾中独立运行。两轮使用不同的 DHCP 地址池、Apache 服务目录与端口、邮件主题和队列 ID。

## DHCP

ISC DHCP 4.3.1 从源码独立构建。Ubuntu 私有接口为 `enp0s17`，地址 `192.168.77.2/24`。本轮分配池为 `192.168.77.21–.49`，`.1–.10` 在池之外。同一事务完成 Discover、Offer、Request、ACK。事务号 `0xd48a099e`，ACK 帧 5，XP 地址 `192.168.77.21`，服务端 `192.168.77.2`，租期 **3600 秒**。 XP 网络连接明细实拍确认本机地址为 `192.168.77.21`、DHCP 服务器为 `192.168.77.2`，可见租约起止时间。 对照 [XP 客户端实拍](截图/D04-XP网络连接租约明细.png) 和 [本次补拍抓包字段](实测/XP续租报文.tsv)。 XP 自带网络诊断向 DHCP 服务器发出 4 次 ICMP Echo Request，Ubuntu 返回 4 次 Echo Reply。原始 [ICMP 抓包](实测/icmp.pcap) 与 [解码日志](实测/icmp.log) 已归档。快速再次续租时复用现有到期时间，最后一帧 ACK 记录余量 3594 秒，与补拍图里的时间差一致。

对照 [dhcpd.conf](配置/dhcpd.conf)、[构建记录](实测/dhcp-build.log)、[服务日志](实测/dhcp-service.log) 和 [截图索引](截图/截图索引.md)。同一隔离接口依次切换两池。若包中包含过渡文件，它记录旧址短租约换池过程，正式租约以本轮 3600 秒 ACK 为准。B 轮首次成功发生在过渡测试之前。过渡测试对旧址发出 60 秒 Offer，随后 ACK 复用了旧租约，字段为 1388 秒。该过程见独立抓包，与正式 B 轮证据分开。

## Apache

Apache 2.4.71 从源码构建。站点根目录 `/opt/netlab4/a/site`，站点名 `web-a.lab4.test:18080`。宿主 Edge 访问 `192.168.174.129:18080/welcome.htm` 与 `/status.html`，两页均显示本轮内容。宿主通过 `curl --resolve` 把实验域名请求映射到来宾 IP，两页均返回 HTTP 200。浏览器后续缓存命中可在日志中出现 HTTP 304。

对照 [Apache 配置](配置/httpd.conf)、[构建日志](实测/web-build.log)、[宿主 HTTP 记录](实测/web-host-http.log)、[Apache 访问日志](实测/access_log) 和 W01–W05。

## Postfix

APT 安装 Postfix `3.3.0-1ubuntu0.4`。完成本地去程和返程投递。外部邮件主题 `LAB4-MAIL-20261118-A`，Ubuntu 外发队列 `9F1B386A61` 经证书验证通过的 TLS 连接送达 Foxmail SMTP 中继，返回 `250 OK`。校邮网页打开了本轮原信。校邮回信发回 Foxmail，Ubuntu 用只读 IMAP 按准确的回信主题、发件人、时间和引用原正文匹配，再交给 Postfix 写入 `lab4ma@localhost`，本地投递队列 `02AFE86A79`。

校邮回复未带 In-Reply-To 和 References。回信采用 IMAP 拉取后本地投递。首发因 APT 的 Local only 默认传输方式在本机退信，修复 SMTP 传输配置后成功。对照 [本地投递](实测/mail-local-bidirectional.log)、[外发回执](实测/mail-smtp-redacted.log)、[TLS 日志](实测/postfix-tls.log) 和 [回信落地](实测/mail-reply-delivery-redacted.log)。

## 操作位置与复核

- 来宾源码和独立构建目录在 `/opt/netlab4/a/`，共用的已校验压缩包在 `/opt/netlab4/sources/`。Apache 页面、Apache 配置和 ISC DHCP 配置已导出至 [配置](配置/)。
- 来宾执行脚本为 `/opt/netlab4/start-dhcp.sh`、`/opt/netlab4/build-web.sh`、`/opt/netlab4/start-web.sh`、`/opt/netlab4/setup-postfix.sh` 和 `/opt/netlab4/import-test-reply.py`。回信导入需使用获授权的客户端配置。
- XP 客户端取证采用 Network Connection Details 界面。该界面显示地址、掩码、服务器和租约起止。来宾主动连通性由 XP 内置 Network Diagnostics 发起，D06 是 Ubuntu 端实际抓包的终端画面。
- 记录时间以 Ubuntu UTC 为主。校邮网页显示北京时间。截图逐项说明见 [截图索引](截图/截图索引.md)。本目录文件可按 [SHA-256](SHA256SUMS.txt) 复核。
