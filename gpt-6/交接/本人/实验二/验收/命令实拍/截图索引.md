# 实验二 A 轮命令窗口实拍

2026-11-18 使用同一台 Windows 11 宿主机分别实际执行两轮命令，直接捕获命令窗口。下列图为本次补测，指导书所列 Windows 7 不在本机实验环境内。

公网测试用 www.baidu.com，普通 ping 收到 4/4，指定载荷 56 字节收到 3/3。固定地址 36.152.44.93 的 `ping -r 9` 收到 2/4 并显示路由记录，`tracert` 在第 12 跳到达同地址。文档保留地址 192.0.2.1 在 8 跳内未达。早期实验两轮的 Record Route 都超时，公网路径及统计数值应分别按对应轮次和时间记录。

局域网补测走 VMware VMnet8，宿主为 192.168.174.1，Ubuntu 为 192.168.174.129。两轮普通 ping 4/4，指定载荷 ping 3/3。原实验所用 XP → Ubuntu 私有 LAN、XP 的 DHCP 释放与续租以及关联进程的 netstat 结果仍见原始日志和原 Wireshark 抓包。本次 VMware Tools 未响应来宾执行，XP 的 ipconfig /release、/renew 和管理员 netstat -b 原生窗口图待补。
