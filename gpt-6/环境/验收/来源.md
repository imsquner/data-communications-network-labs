# 镜像和工具来源

文件名和本机 SHA-256 见 SHA256SUMS.txt，文件路径相对于环境目录。

- Ubuntu Server 18.04.6 amd64，下载自 https://mirrors.ustc.edu.cn/ubuntu-releases/18.04.6/ 。SHA-256 与同目录 SHA256SUMS 一致。
- Windows XP Professional SP3 x86 英文零售版，下载自 https://archive.org/details/en_windows_xp_professional_with_service_pack_3_x86_cd_x14-80428_202010 。SHA-1 为 1c735b38931bf57fb14ebd9a9ba253ceb443d459，与 https://learn.microsoft.com/en-gb/answers/questions/2431828/needing-to-know-if-windows-xp-professional-with-sp 所列一致。
- Cisco 3640 IOS 12.4(25d)，从 https://drive.google.com/file/d/19o2iNLL8zNU6mYWM0UgYdZh1AXuuAn7f/view 中的压缩包提取。MD5 为 493c4ef6578801d74d715e7d11596964，与 https://gns3.com/marketplace/appliances/cisco-3640 的模板值一致。
- GNS3 2.2.61，下载自 https://github.com/GNS3/gns3-gui/releases/tag/v2.2.61 ，SHA-256 与发行页一致。
- Wireshark Portable 4.6.9，下载自 https://mirror.nju.edu.cn/wireshark/win64/ ，SHA-256 与 https://lists.wireshark.org/archives/wireshark-announce/202609/msg00000.html 的官方值一致。
