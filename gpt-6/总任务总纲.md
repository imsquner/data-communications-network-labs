## 逐项实施与验收

- 预检。确认 C++ 编译器、Wireshark 抓包接口和权限、GNS3/Dynamips 的 3640 IOS 与网口模块，以及 VMware、Ubuntu 18.04 和 XP 来源。先核对课程视频和课程官方资源入口。优先采用指导书环境，无法取得所需镜像时就具体替代项请老板确认。
- 实验一。独立实现 C++ CRC-16/Modbus 和 7 位 ASCII 海明码。覆盖 CRC 0–10 位与海明码 0–11 位干扰，保留固定种子、逐项输出和多次试验统计。用手算样例对照生成与校验，记录单比特纠正和多比特误纠、漏检。报告包含生成、校验、纠错及批量试验流程图、代码与运行结果。
- 实验二。执行 ping、ipconfig、netstat、tracert 及指导书指定参数。DHCP 释放和续租在独立实验接口上做。抓取 DHCP 地址分配和 IPv4 分片，保留 pcapng、命令输出、截图和帧号。对照同站点 ping -r 与 tracert，回答指导书关于 ICMP、IP 首部长度、有效载荷、分片和 Identification 的问题。按本次抓包解释字段变化。
- 实验三。搭 GNS3 的双交换机四 VPCS 拓扑，验证同网段、异网段、划子网和 VLAN 200/300。另建双路由器拓扑，分开保留直连基线、静态单边与双边、RIPv2 和 OSPF 配置。记录 RIP 断链撤路和恢复更新、OSPF 邻接与路由条目。提交拓扑、配置、路由表和连通性截图，说明各阶段路由与回程的影响。
- 实验四。VMware 隔离网络内配置 Ubuntu 18.04 与 XP。源码编译 ISC DHCP 和 Apache，使用软件包安装 Postfix。验证 DHCP 前十个可用地址预留、租期 3600 秒和 XP 客户端租约。宿主机浏览器分别验证 htm、html。邮件按实际测试分别记录 SMTP 投递、收件与回信，外部收发条件不足时保留日志并明确结果边界。
- 报告。使用项目根目录的 学生实验报告模板.docx，保留实验分析与设计、过程记录、结果分析结构。四项实验的图、数据、日志与问答逐项对照四份官方指导书。更新目录，核对封面、分页、图注、文件大小与占位符。提交版计划落在 gpt-6/交付/，执行证据按实验分别归档在 gpt-6/实验/。验收后交老板检查，由老板提交。
