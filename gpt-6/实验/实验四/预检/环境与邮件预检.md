# 实验四环境预检

2026-11-17。预检覆盖宿主、现有 VMware 运行状态、构建材料和无凭据 SMTP 探测。

## 已验证

- `vmrun list` 返回两台实验来宾，Ubuntu Server 与 XP Professional 均在运行。Ubuntu 和 XP 的 VMX 都使用同一私有 LAN Segment。两个回环 VNC 端口 `127.0.0.1:15901`、`127.0.0.1:15902` 均监听。两台来宾当前均无 VMware 快照。
- VMnet1 为仅主机网，宿主地址 `192.168.37.1/24`。VMnet8 为 NAT 网，宿主地址 `192.168.174.1/24`。两段当前均启用 VMware DHCP。宿主 Dumpcap 成功枚举这两个接口。XP 的 ISC DHCP 应在私有 LAN 由 Ubuntu 私有接口抓包。
- 已下载 ISC DHCP 4.3.1 和备选 4.4.3-P1。ISC 使用 `.sha256` 文件名提供 OpenPGP 签名，GnuPG 两次均返回 `VALIDSIG` 和退出码 0，签名当时有效，签名密钥现已过期。Apache 2.4.71 源码与发布的 SHA-256 一致。源码、签名、核验日志、[SHA-256 清单](源码/SHA256SUMS.txt) 同目录。
- 宿主访问 Ubuntu Bionic、Bionic Updates、Bionic Security 的 InRelease 均获 HTTP 200。直接读取仓库清单，确认可见 Postfix、build-essential、libapr1-dev、libaprutil1-dev、tcpdump，libpcre2-dev 在 Bionic Universe。实际来宾的候选包以届时 `apt-cache policy` 为准。

## 邮件出口预检

- 从 Windows 宿主发起 SMTP 握手，QQ `smtp.qq.com:465` 与 `:587` 均返回 EHLO 250、TLS 1.3。163 `smtp.163.com:465` 返回 EHLO 250、TLS 1.3，其 `:587` TCP 可连，SMTP 问候超时。Google 测试 MX 的 TCP 25 返回 EHLO 250、TLS 1.3，仅作直连对照。
- 探测没有输账户、认证、提交测试邮件或接收邮件。Ubuntu 来宾当前 VMX 没有启用 NAT 接口，宿主结果不能代替来宾出站验证。VMware Guest Operations 当前也无法回传 Ubuntu 的 IP，错误为 VMware Tools 没有运行。正式执行先从本地控制台核验来宾接口、软件源和访问路径。
- 建议由一个可用 SMTP 提交的测试邮箱发件，发送给老板的常用邮箱。从常用邮箱回复到测试发件箱可形成公网邮件往返。若要证明回复抵达 Ubuntu，需要另有已授权的服务商收件后取信路径，或者现成的公网接收设施。后续分别记录远端接受、常用邮箱收件、回复到达测试邮箱和回复是否进入 Ubuntu。
- 需老板决定发件服务商及测试发件账号、常用收件地址、回信是否需要进入 Ubuntu。需登录或生成授权码时由本人在本机设置，凭据不上交接材料。
