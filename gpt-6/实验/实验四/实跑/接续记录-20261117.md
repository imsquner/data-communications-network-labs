## 二、关键技术结论（明天直接复用，别再踩坑）

| 能力 | 结论 |
|---|---|
| VNC 截图 | ✅ `vncdotool` 直连，出图清晰可靠 |
| VNC 键盘（字母/数字/空格/连字符） | ✅ 可靠，单键=单字符 |
| VNC 键盘（特殊符号 `|` `\` `"` `'` `<` `>` 等） | ❌ **会错映射**（`|` 打成 `\`），命令里避免特殊符号 |
| VNC 快速打字 | ⚠️ 疑似偶发重复，**慢速输入 + 截图核对后再回车**最稳 |
| `vmrun` 来宾操作（runProgramInGuest 等） | ❌ VIX 故障，报"file not found"，不可用 |
| PowerShell `Add-Type` | ❌ 被本机沙箱拦截，Win32 走 Python ctypes |
| VMware 内置 VNC | ✅ 比窗口抓图/焦点注入可靠，是主通道 |

**核心策略：SSH 才是长期命令通道。** VNC 只用于截图和"打开 SSH"这一步。装 openssh-server 后，所有命令（编译、apt、传文件）都走 SSH，彻底规避 VNC 打字问题。
