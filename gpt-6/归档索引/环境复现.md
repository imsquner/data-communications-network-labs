# 环境复现说明

## 版本与出处

- 宿主为 Windows。实验一采用 C++17。构建、用例和输出见 [实验一实施记录](../实验/实验一/实施记录.md)。
- 实验二保留了 Windows 宿主和 Windows XP 来宾的实拍与日志。抓包环境为 Wireshark Portable 4.6.9，捕获驱动为 Npcap，接口环境包含 VMware 隔离网段。按 [实验二验收说明](../实验/实验二/验收说明.md) 对照抓包字段和历史命令。
- 实验三采用 GNS3 2.2.61、Dynamips、Cisco 3640 IOS 12.4(25d)、VPCS。准备有权使用的同版本 IOS，再在 GNS3 导入两套交接目录内的对应工程。节点接口、IP 和实测流程见 [A 轮说明](../交接/本人/实验三/验收说明.md) 与 [B 轮说明](../交接/室友/实验三/验收说明.md)。
- 实验四采用 VMware 隔离网络、Ubuntu 18.04 系列来宾和 Windows XP Professional SP3，配置 ISC DHCP 4.3.1、Apache 2.4.71 和 Postfix 3.3.0-1ubuntu0.4。四号实验的安装与排障步骤见 [实施计划](../实验/实验四/实施计划.md) 和 [续跑方案](../实验/实验四/续跑方案-20261118.md)，实测配置分别在 [A 轮](../交接/本人/实验四/配置/) 与 [B 轮](../交接/室友/实验四/配置/)。公网邮件复现需要自行配置获授权的邮箱。

[历史下载来源](../环境/验收/来源.md) 记录获取时的来源和发布校验信息。[环境文件校验](环境文件校验.tsv) 记录本次读取计算的 SHA-256、字节数和路径。路径相对于原课程目录，散列对应本机现存文件。可在原目录用 PowerShell 的 Get-FileHash -Algorithm SHA256 核对单个文件。

## 证据来源与边界

- 原实跑的 8 个 GNS3 包在原路径保留精简副本，保留条目的 CRC 和路径已对照原包。本人、室友交接目录各 4 个 GNS3 包沿用原始交接版本。工程依赖 IOS 文件，本次对压缩包与拓扑做静态核对。
- 本人 A 轮 M05 校邮截图在仓库使用 Word 中已遮盖的版本，A 轮实验四的 SHA256SUMS.txt 随之更新。实验四预检 QW01 原图包含邮箱地址，原图留本地。用于报告的其他邮件截图和脱敏日志保留。可在 M04/M06 日志和截图对照实验生成的 Message-ID、主题、队列 ID 与投递状态。
- 对报告结果优先使用附件审阅修订版。历史 A 轮交接中的 web-host-http.log 与 B 轮端口相符，A 轮网页以 W03、W04 及 A 轮访问日志为依据。实验过程和已知限制见 [问题留存](../问题留存.md)。
- 本地保留的虚拟机、第三方安装介质、凭据、含身份信息的原始邮件、工具解包树和缓存见 [本地保留清单](本地保留清单.tsv)。表里有些路径在仓库存在一个经处理的副本，原因栏注明具体处理。
