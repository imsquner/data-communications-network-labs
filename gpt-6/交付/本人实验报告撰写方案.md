## 二、模板结构和首页字段

- 原模板有统一封面、教学管理规范和四套实验项目表。沿用每项的三个部分：实验预习报告、实验过程记录、结果与讨论。结果与讨论按模板包含结果分析、小结及思考题。

## 三、按实验执行

### 实验一　检错纠错码

- **预习和设计。** 说明 CRC-16/Modbus 初值、反射多项式和低字节先附加，说明 7 位 ASCII 在 11 位海明码中的数据位、校验位与综合征。将 A 轮验收说明中的五个流程图重新渲染为 CRC 生成和校验、海明码生成和纠错、批量实验各一张。
- **过程和证据。** 记录固定种子 20261117、C++17 编译命令、参考向量、手算样例 E6 的 CRC 和海明码单错样例，再描述随机选互异位号、翻转、校验或纠错。将编译核验、逐位注错、海明码与漏检样例三张图标明为运行记录摘录，图注写明对应的原始日志。
- **结果和讨论。** 用一张 CRC 表和一张海明码表覆盖 23 组、每组 10,000 次。CRC 参考值 4B37，80/80 单比特检出，4 位组漏检 4 次、8 位组漏检 1 次。海明码单比特 1,408/1,408，双位组误纠 7,095、拒绝 2,905，11 位全翻转在本实现中综合征为零。解释分组结果和样本边界。随机填充的额外参数、注错与打印的拆分如实说明。

### 实验二　网络命令、DHCP 与 IPv4 分片

- **预习和设计。** 用简表说明 ping、ipconfig、netstat、tracert 及此次用到的参数。先画 XP 私有网、VMnet1 抓包和 Windows 11 宿主公网的环境关系，注明补拍的宿主到 Ubuntu 验证经 VMnet8。指导书写 Windows 7 和物理网卡，正文按实际环境填写。
- **过程和证据。** 按命令测试、DHCP 释放及续租、ICMP 和 IPv4 分片分段。公网用 11 月 18 日原生命令图，写百度普通 ping 4/4、固定 IP 的 Record Route 2/4、tracert 第 12 跳。11 月 17 日原结果为 0/4、第 16 跳，保留作复测对照，图注带日期。XP 的释放、续租、管理员 netstat -b 以原始日志行和对应抓包支撑，注明缺命令窗口原图。
- **结果和思考题。** 按指导书六问逐项作答。以图 06 解释 DORA、单播续租和 Release。用图 07 的第 21 帧给出源 192.168.37.128、协议 1、首部 20、总长 60、负载 40 字节及未分片判据。用图 08–09 和四行表复核第 29–32 帧，ID 0x00cf、偏移字段 0/185/370/555、MF 与 5,008 字节重组。另解释 Source 排序、显示过滤器可见范围、同一数据报各片共享字段和不同请求的 Identification 变化，以及 DF 1472/1473 边界。

### 实验三　交换机与路由器配置

- **预习和设计。** 按交换、静态路由、RIPv2、OSPF 四个项目写拓扑、地址和观测目的。简表解释 IOS、VPCS 的主要命令，思考题给出 R1 e0/0 的完整配置命令，包括进入接口、IP/掩码、启用和核查。
- **过程和证据。** 交换项目保留同网段、异网段、两个 /25、VLAN 200/300 对照，用端口表说明 VLAN 200 access 互联和 VLAN 300 断开原因。静态项目保留直连、单边、双边截图，用 R2 缺回程路由解释单边失败。RIP 以报告重拍的断链前、撤路、在线重接、debug 及恢复双向 ping 为同一次证据链；如补述早期重启兜底，在过程记录中另列。OSPF 用两端 FULL、O 路由与终端连通截图。
- **结果和思考题。** 用简表横向比较 C、S、R、O 条目，解释前缀、下一跳、出接口、管理距离和度量。分别回答静态单边为何不通、RIP/OSPF 配置前为何只有直连网络、配置后哪些探测恢复。71 项探测写为实测与预期匹配，其中包括预期失败。

### 实验四　DHCP、Web 与邮件服务器

- **预习和设计。** 写 Ubuntu 18.04 与 XP 的隔离 LAN，以及宿主访问网页和 Ubuntu 出站邮件的 NAT 路径。交代 ISC DHCP 与 Apache 源码构建、Postfix 软件包安装，以及本次 Linux 命令的用途。
- **DHCP。** 依 E01、D01–D06 记录构建、配置、监听、客户端明细、DORA 和 XP 主动 ICMP。本人池 192.168.77.21–49，前十地址留在池外，正式 ACK 帧 5、租约 3,600 秒、XP 地址 .21，ICMP 4/4。补拍续租余额 3,594 秒如出现，说明是复用原租约后的剩余时间。初始 XP 基线只有历史图，缺无指针版本。
- **Apache。** 依 W01–W05 串起构建、站点目录与监听、浏览器两页、HTTP 200 和日志。写清 18080、web-a.lab4.test、DocumentRoot、Directory、ServerName 与宿主 curl --resolve 的对应关系。
- **Postfix。** 依 M01–M06 串起安装、环回监听、本地投递、SMTP 外发 250 OK、校邮收件、回信取回和本地落地。用主题及队列 9F1B386A61、02AFE86A79 复核。外发经过 SMTP 中继，回复由只读 IMAP 拉取后在 Ubuntu 本地投递。敏感字段使用遮盖版；核对本人原网页图，必要时在报告工作副本做遮盖。
- **结果和思考题。** 分别回答源码编译与 apt-get 的取舍、如何更改网站根目录和域名、邮件为何能够在 Ubuntu 看到。按本人正式日志的 DHCP → Web → 外发时序写，保留现场遇到的 NAT 配置错误和 Postfix Local only 退信及处理经过。
